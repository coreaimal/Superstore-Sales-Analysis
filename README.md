# Superstore-Sales-Analysis
A sample dataset from kaggle called "Sample-Supertore" was downloaded and some analysis was performed on it. Some key findings were found on this dataset which can help the company change their approach in certain where required.
Exploratory data analysis of retail sales data using Python, uncovering trends in profitability, discounting, and customer value.
## Key Findings
- Sales show strong year-over-year growth with a seasonal peak every Q4
- Discounts above 30% consistently produce losses
- Furniture underperforms other categories, especially in the Central region
- A small group of top customers drives a disproportionate share of revenue

## Tools
Python, Pandas, Matplotlib, Seaborn

[Superstore Dataset – Kaggle](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)
